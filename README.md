# Portfolio V3

Monorepo: Astro public site + Hono API + Next.js admin + Client Portal.

- `apps/public` — Astro (live/SSR)
- `apps/api` — Hono, the single backend
- `apps/admin` — Next.js admin (OpenNext)
- `apps/portal` — Client Portal (last phase)
- `packages/*` — shared packages (auth, database, ui, cms, media, seo, ...)

See `docs/ARCHITECTURE.md` for the full plan.
